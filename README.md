## Purpose

This repository is intended to become a clean, searchable, contributor-friendly archive for KMIT Semester 2-2 notes and study resources.

The long-term goal is to keep material organized by subject, avoid unnecessary duplication, preserve useful original filenames where practical, and make future batches easy to maintain.

## Semester

Semester: **2-2**

This repository is isolated to Semester 2-2 material only. Content for other semesters belongs in the corresponding repositories under the KMIT Notes organization.

## Planned Structure

The final taxonomy will be decided after auditing the available material. A likely structure is:

```text
subject-name/
├── README.md
├── notes/
├── assignments/
├── lab/
├── question-papers/
└── resources/
```

Subject names will be added only after the actual source material is inspected.

## Contributing

Contributions are welcome once the initial structure is finalized.

Please keep contributions predictable and maintainable:

- Add material only to the correct semester repository.
- Organize content by subject where possible.
- Avoid duplicating the same file across repositories.
- Prefer clear, searchable filenames.
- Clearly distinguish student-contributed material from official KMIT material.

## Content Disclaimer

This is a community/student-maintained notes archive. It is not an official KMIT repository and does not imply endorsement by KMIT.

If any material is inaccurate, outdated, private, copyrighted, or should not be shared, please report it through the repository once issue tracking is enabled.
